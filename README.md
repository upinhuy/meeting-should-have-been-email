## The entry

> We held a meeting about the email, then sent an email to schedule a meeting about the meeting we'd just had about the email.

One line, plain text, under 200 characters — a single joke about a meeting
that should have been an email. No code, no attachments, no second line.

## How it works

`main.ts` (Node 22+, TypeScript as-is, standard library only) validates the
line — 1–200 characters, a single line, not only whitespace — and writes it
to `/output/entry.txt`, exactly as the kit's contract requires:

```sh
node main.ts
cat /output/entry.txt
```
